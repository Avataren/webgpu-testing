# Robotron 2084 (a modern take)

A 3D twin-stick arena shooter after the 1982 original, built entirely through the engine MCP.
The game boots into an attract mode where an autopilot plays a demo game under the title;
press Enter to take over.

## Run

```
# editor: open games/robotron (project_open), then press Play
# player:
cargo run --bin player -- games/robotron      # or engine_launch {target: "player", project: ...}
```

## Controls

| Input | Action |
| --- | --- |
| `W A S D` | Move (8 directions) |
| Arrow keys | Fire (8 directions; hold two for diagonals) |
| Left mouse button | Fire toward the cursor |
| `Enter` / `Space` / click | Start a game from the attract screen |
| `B` | Toggle the autopilot during a game |
| `P` | Pause |
| `Esc` | Back to the demo |

## Rules (as in the original)

- One hit kills you. Three lives; an extra life every 25,000 points.
- A wave ends when every *killable* enemy is gone. Electrodes and hulks do not count and vanish.
- Rescue the family (Mommy, Daddy, Mikey): 1000, 2000 ... up to 5000 points each, rising within a wave.
- **Grunts** (100) chase you in short bursts and get faster every wave.
- **Electrodes** are static and deadly; shooting them is optional.
- **Hulks** cannot be killed, only pushed back by shots. They crush the family.
- **Brains** (500) turn the family into **Progs** (100, fast chasers) and fire homing missiles (50).
- **Spheroids** (1000) drift around spawning **Enforcers** (150), which shoot aimed sparks.
- **Quarks** (1000) spawn **Tanks** (200), whose shells ricochet off the walls.

## Files

- `content/scripts/robotron.lua`: the whole game (one controller; every actor, bullet and spark is
  spawned and pooled by the script). Section comments mark the actor definitions, wave table,
  enemy AI, collisions, effects, the autopilot, game flow and HUD.
- `content/audio/*.wav`: generated by `python3 tools/gen_audio.py content/audio` (needs numpy).
- The arena (floor, grid, border), lights and camera are ordinary scene entities.

## The autopilot

`bot_think` in the script plays the game: every 70 ms it simulates the player's eight moves 0.7 s
ahead against predicted enemy and projectile positions and picks the safest one, leaning toward
the nearest family member that no hulk or brain is near; every 50 ms it picks the firing direction
that lines up the most valuable targets (leading moving ones, skipping those a hulk or electrode
blocks). With family left and the wave nearly over it stops shooting at distant enemies so there
is time to rescue them.

## Testing hooks

`GAME` holds the state and cumulative `GAME.stats`. A global `RT` table (use
`lua_eval {entity: "GameController"}`) has `RT.jump(wave)`, `RT.spawn(kind, x, z)`, `RT.god(true)`,
`RT.bot(false)`, `RT.kill()`, `RT.lives(n)`, `RT.units(kind)`, `RT.count()` and `RT.new(demo)`.
A soak test: `playtest {seconds: 45, time_scale: 16, lean: true, entity: "GameController",
eval: "return GAME.stats"}`.
